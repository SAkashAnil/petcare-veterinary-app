# PetCare — Veterinary Health and Animal Care

## Project overview

PetCare is a proposed mobile application concept designed to help pet owners understand common health concerns, access animal-care information, receive preliminary symptom guidance, and find suitable veterinary professionals.

The project originated from a client briefing for a veterinary medicine company. The proposed application is intended to operate separately from the company's existing medicine business.

## Project objectives

- Help owners describe and understand possible pet health concerns.
- Provide preliminary guidance and appropriate next steps.
- Offer animal information covering diet, habitat, behaviour, exercise, and common health concerns.
- Help users find veterinarians and review appointment options.
- Document proposed API endpoints for the application's major features.

## Scope

The current deliverable is a non-interactive wireframe and supporting product documentation. This repository does not contain a working application, live backend, or connected veterinary booking service.

User research and usability-test findings should be documented only after the activities have been conducted.
